# محمد نوروزیان عزیزی

من محمد نوروزیان هستم و تمرکز LCENJ روی آموزش، معرفی و تامین قطعات، بردها و ماژول‌های کاربردی الکترونیک است. هدف سایت این است که خرید، یادگیری، پرسش و پاسخ و اجرای پروژه‌های الکترونیکی برای کاربران ساده‌تر و قابل اعتمادتر شود.

اگر برای انجام پروژه، طراحی مدار، انتخاب قطعه یا ساخت نمونه اولیه نیاز به همراهی دارید، از صفحه تماس با ما پیام بفرستید.

## نمونه‌کارهای منتخب

- برد کنترلر کارواش هوشمند مبتنی بر STM32 با ورودی و خروجی‌های متعدد، سنجش دما و رطوبت و پشتیبانی UART و RS-485
- توسعه سخت‌افزار و Firmware سامانه‌های امبدد، کنترل صنعتی، پایش و ارتباطات
